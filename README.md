# Proforma Viewer v1.2.0

Full-screen Windows WPF application. Click tiles to select them, export selected PDF pages, open the current database folder, or change fleet. The workbook reader safely ignores blank and duplicate headings and locates the Title/Path/Page header row within the first 20 used rows.

Upload the full contents to the GitHub main branch. The Build workflow produces a self-contained `ProformaViewer-win-x64` artifact.
